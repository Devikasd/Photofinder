# Photofinder
Wedding photo sorting script
Goal
Build a private, shareable web app where anyone (friends/family) can:
upload 1–5 reference photos of themselves
click “Find my photos”
receive a downloadable ZIP containing only the wedding photos where they appear
Critical requirement: Users must NOT get access to the full photo library (no Drive folder access, no browsing, no write permissions). They should only receive their matched photos.
